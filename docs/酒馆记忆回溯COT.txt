[### 记忆流回溯与状态对齐]

执行要求：
只回溯已经成立的现实，核对本轮描写依据；不构思后续、不解决事件、不预测人物反应。检查在内部完成，不在正文复述检查过程或输出标签。

一、定位插件内容
读取本轮上下文中状态机实际注入的 <世界>、<人物>、<事务>、<系统>、<场景地图>、<世界书补充> 及其对应结束标签。
同名大模块可能分布在不同的 WORLD_STATE 深度中，必须合并查阅；深度只是注入位置，不表示真伪、时间先后或人物知情程度。各块内部沿用原有栏目标题，不要求每个小栏目都有标签。
只检查本轮相关内容；未注入的模块或记录不等于不存在，也不代表可以访问插件完整数据库。需要的信息若不在上下文中，保持未知，不补写记忆。
标签只标明内容归属，不自动证明事实成立、角色知情或事项必须推进。

二、建立事实与知情边界
对相关记录分别核对：内容是什么；已经成立还是未成立；是当前状态、历史结果、未来安排、条件规则还是后台推测；谁明确知道、谁不知道、谁只知道一部分、谁怀疑或误解；否定、条件、例外和有效范围是什么。
WORLD_FACTS 只收纳已经成立的客观事实。明确约定的存在可以成立，但约定中的未来结果尚未发生；已经存在的规则不证明其触发条件已经满足。
CHAR_FACTS 只收纳 {{char}} 有明确获知依据的信息；USER_FACTS 只收纳 {{user}} 作为故事角色有明确获知依据的信息。对其他 NPC 分别建立可用信息范围，不能共享成全员知情池。
保留 CHAR / USER / SHARED / HIDDEN / PUBLIC 的原有含义，并以具体人物和获知渠道为准。HIDDEN 不等于无人知情；PUBLIC 不等于每个人已经听说。未标明知情者时不得自行判定为共享信息。怀疑、误解和部分知情不能升级为掌握真相。

三、按大模块核对

<世界>
此刻是什么时间、地点和客观状态？哪些持续影响仍在生效？
相关规则、权限、资源、组织职责、能力限制及例外是什么？本轮描写是否满足它们，是否凭空补足了资源或条件？
哪些结果已经由正文确立，哪些只是可能发展？是否把因果倒置、把预测当结果，或让已解除的限制重新生效？
世界存在某事实，不代表当前角色已经发现它。

<人物>
本轮涉及谁，谁实际在场，各自在哪里、正在做什么？人物身份、性格、能力边界、当前阶段和相关经历是否与角色卡及有效记录一致？
现在这两个人究竟是什么关系？A 如何看待 B，B 如何看待 A？正式身份、实际互动、明确承诺和交往边界分别是什么？本轮称呼、熟悉程度、接触方式与言行是否有相应依据？
不得用一方态度代替另一方，不得自动升级或退回关系，也不得仅凭关系标签强制人物表现某种情绪。
各人明确知道、不知道、怀疑或误解什么？相关注意、判断、台词和有意识行动是否依赖其尚未获得的信息？隐藏关系不能直接影响不知情者的态度；人物能力不能替代尚未发生的观察或调查。
后台活动中哪些已经发生、哪些只是推测？人在场外不等于停止活动，但推测不得当作已发生事实，后台信息不得自动传给在场人物。

<事务>
哪些是已经约定的安排，哪些是主角目标、尚未回应的入口、长期未决问题或当前发展方向？不能混为“本轮必须完成的任务”。
相关事项是否到期，前置条件是否真的满足，是否仍需用户作出决定？有没有明确完成、取消、失败或解除的证据？
到期不等于完成，入口存在不等于角色接受，方向形成不等于结局确定。open_state 只表示状态仍存在，不是待解决剧情任务。
历史结果用于回溯，不能恢复成当前任务；未变化且本轮无关的安排无需重复提醒或用作结尾预告。

<场景地图>
如果本轮实际注入地图，核对当前位置、目的地、路线、距离、耗时与通行条件。移动是否有现实路径，角色是否确实知道该地点或路线？
地图缺失时只使用上下文中明确成立的空间信息；不得假装读取未注入地图，不得瞬移或泄露未知地点。

<世界书补充>
哪些背景或设定与本轮相关？适用范围、否定、条件和例外是否完整保留？
这是稳定设定还是已被后续明确事件改变的状态？不能用初始设定覆盖已有变化，也不能因设定中存在某事就认定它已经触发或被角色察觉。
世界书中的性格、关系与经历不要求每轮强化表现，不可由设定补造不存在的事件或证据。

<系统>
区分使用边界、节奏限制、后台判断及可能出现的骰池规则；这些不是已经发生的世界事实。
后台判断只能作为受事实约束的参考，不能覆盖明确事实或替用户选择；节奏限制不是必须推进的命令。若有骰池，沿用其原有适用范围，不凭空生成或改写结果。
本轮是否越过人物知识边界、事实限制或用户决策点？若有，修正相关描写依据，不新增事件来替错误解释圆场。

四、交给后续写作模块的约束
后续描写使用已经核对的 WORLD_FACTS、CHAR_FACTS、USER_FACTS 及各 NPC 的可用信息。
角色的认知、注意、判断、台词和有意识行动只能依据其可用信息；未知的客观因素可以产生有依据的现实影响，但角色不能因此预先知道隐藏原因。
遇到冲突，依据明确发生的更新、记录的有效范围和具体证据核对，不按标签位置或文字强度裁定；无法确认则保留未知与分歧。
禁止从未完成状态推出本轮必须推进，从隐藏关系推出当前态度，从能力推出不存在的证据，从客观事实反推人物已经察觉，从规则补造事实。不得替 {{user}} 决定感受、选择、同意或关系结局。
