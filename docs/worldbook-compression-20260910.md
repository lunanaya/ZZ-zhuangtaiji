# v0.16.74 世界书规则简写

用户允许将尚未完整融入状态、仍需回传的世界书文字压缩为便于 AI 阅读的规则，但要求不新增、不遗漏、不改动原意。

## 实现范围

采用本地可逆的规则简写。重复的完整规则或长前提放入“规则短语”表，正文按原顺序引用对应符号。定义保留原文，重复出现的次数、上下文、条目顺序和其他文字原样保留。来源中的既有符号会避让，定义不得递归引用。

这项保证来自逐字展开核验，不依赖模型自称语义等价。没有重复片段的长描述可能无法缩短，继续用原文；目前没有实现任意长散文的语义改写。不能把匹配关键词、保留几个数字或模型的“完整”标记当作等价证明。

校验同时要求：

- 展开后与接管原文逐字一致，含标点、换行、否定、条件、例外、数字、顺序、模态和知识边界。
- 每个定义必须实际用于正文、确实来自原文；未使用的额外定义也拒绝，防止夹带新信息。
- 计入简写说明和结构后仍比原文短。没有预设压缩比例，不按字符数截断。

发送路径为 `WorldbookMemory.fallback → transmission → PlainMemory.composeByDepth → Engine 注册提示`。状态已经完整逐字回传该条原文时仍不重复补发。手动修改状态结论不会关闭必要的世界书补充。

`worldbookSources` 始终保存原文，不用简写覆盖；分析状态时仍读原文。简写由原文即时计算并保留最多32项派生缓存，原文改变自动失效，不增加存档版本或 API 请求。已有接管内容刷新后即可使用；旧档若尚未接管世界书，仍须先读取资料。

“世界书 → 世界书承接”显示精简前后字符数，并可展开同时查看实际精简回传和完整原文；“最终注入”显示本轮真实发送形式。

## 验证

- `node dev/smoke-worldbook-compression.mjs`：重复规则、不同结论共享前提、原文顺序、次数、条件/例外/知识边界、源文变化、引号/换行/符号、短文本退回原文；伪造定义、删掉边界、修改前提、重排、递归定义、闲置新增信息均不能通过。
- 构造的重复规则样例从1024字符变为386字符，减少62%；这是样例字符数，不代表真实世界书压缩率或 tokenizer 测量。
- `node dev/smoke-worldbook-memory.mjs`：精简版实际进入注册提示，并可完整还原；既有来源关闭、原文保留、聊天隔离、清空、KEEP防护和界面对照仍通过。
- `node dev/smoke-plain-memory.mjs`：既有初始化2次、正文/整理1次API和全栏目必填保持。
- 本轮全部验证采用本地数据和模拟提供商，没有调用真实付费模型或修改真实聊天。
